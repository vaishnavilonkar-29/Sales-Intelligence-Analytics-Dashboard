# Sales Intelligence & Analytics Dashboard
An interactive sales analytics dashboard built using Python,
Streamlit, Pandas, and Plotly to analyze sales performance,
product trends, category-wise revenue, and promotional impact.
## Features

- Interactive sales KPIs and summaries
- Sales trend analysis
- Top- and bottom-performing product analysis
- Category-wise sales analysis
- Promotion analysis
- Business insights and basic sales forecasting
- Interactive filters and downloadable data

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- NumPy
- Scikit-learn

## Getting Started

### 1. Install Python

Install a compatible version of Python if you do not already have it.

### 2. Clone the repository

```bash
git clone https://github.com/vaishnavilonkar-29/AI-Sales-Intelligence-Dashboard.git
cd AI-Sales-Intelligence-Dashboard
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Add the required dataset

The CSV dataset files are not included in this repository yet. Place the required CSV file or files in the expected `data/` directory, using the filenames and paths referenced by the application.

Use a dataset you have permission to share.

### 5. Run the dashboard

```bash
streamlit run app.py
```
